# 🐭 MOUSE AI IPTV Pro v4.0 - Web Edition

تطبيق ويب احترافي لمشاهدة قنوات IPTV عبر المتصفح، يعمل على جميع الأجهزة (جوال، تابلت، كمبيوتر).

## ✨ المميزات

- 🔥 واجهة Fire-Glow احترافية (أخضر، أحمر، أبيض على خلفية داكنة)
- 📺 مشغل فيديو HLS.js يدعم بثوث IPTV المباشرة
- 🔍 محلل أكواد IPTV تلقائي (CCcam, Newcamd, Xtream, MAC, Portal, Stalker)
- 📁 تحميل قوائم تشغيل M3U من رابط أو ملف محلي
- ⭐ نظام مفضلات + إدارة سيرفرات مخصصة
- ⚙️ إعدادات متقدمة (صوت، واجهة، شبكة)
- 📱 تصميم متجاوب Responsive مع جميع الشاشات
- ⌨️ اختصارات لوحة المفاتيح
- 💾 حفظ جميع البيانات في localStorage

## 🚀 النشر على Vercel

1. انشئ repository جديد على GitHub
2. ارفع هذه الملفات إليه
3. ادخل إلى [vercel.com](https://vercel.com) واربطه بالـ repository
4. اضغط Deploy - والتطبيق جاهز!
